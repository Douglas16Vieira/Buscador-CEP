#Buscador de CEP
Aplicação web que consulta endereços a partir de um CEP usando a api gratuita do ViaCEP.
## Tecnologias
HTML5, CSS3, Javascript ES6+, API ViaCEP
## Conceitos Aplicados
Consumo de API com fetch e async/await manipulação de DOM, Tratamento de erros

Como Executar:
1. Clone o repositório;
2. Abra o arquivo index.html no navegador web.
